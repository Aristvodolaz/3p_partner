# 3P Partner ТСД — руководство пользователя

Приложение для кладовщиков и операторов ТСД. Через него ведётся вся работа с заявкой партнёра на складе: от приёмки товара до отгрузки, включая размещение на складе и выполнение операций по каждому артикулу (упаковка, маркировка и т.д.).

---

## 1. Первый запуск

1. Откройте приложение — появится список заявок.
2. Если список пустой или показывает ошибку сети — зайдите в **Настройки** (нижнее меню) и проверьте адрес сервера. Обычно он уже прописан по умолчанию, менять не нужно.
3. Если связь с сервером обрывается (слабый Wi-Fi на складе) — приложение само незаметно повторяет запрос 1–2 раза. Если после этого всё равно ошибка — проверьте, что Wi-Fi/сеть вообще есть на устройстве.

---

## 2. Главное нижнее меню

Внизу главного экрана три вкладки — они всегда доступны:

| Вкладка | Что там |
|---|---|
| **Заявки** | Список всех заявок партнёров. Основной рабочий экран. |
| **Склад** | Поиск остатков по адресу ячейки и лента последних перемещений — не привязано к конкретной заявке, для быстрой сверки «что и где лежит». |
| **Настройки** | Адрес сервера. |

---

## 3. Вкладка «Заявки»

- **Поиск** — по номеру заявки или артикулу.
- **Фильтр «К выполнению» / «Все заявки»** — по умолчанию скрыты закрытые и дефектные заявки, чтобы не мешали. «Все заявки» показывает вообще всё.
- Каждая карточка — номер заявки, партнёр, количество позиций, дата, цветной **статус**.
- Тап по карточке открывает заявку.

### Что означает цвет статуса

| Статус | Значение |
|---|---|
| ⚪ Запланировано | Заявка создана, работа ещё не начата |
| 🟣 Приёмка | Идёт/прошла приёмка товара |
| 🔵 Хранение | Товар размещён на складе |
| 🔵 В работе | Выполняются операции по товару (упаковка, маркировка и т.д.) |
| 🟢 Готово | Все операции выполнены |
| 🟢 Отгружено | Товар передан партнёру |
| ⚫ Закрыто | Заявка полностью завершена, документы сформированы |
| 🔴 Дефект | Отдельная претензия/брак — вне обычной цепочки |

**Статус в большинстве случаев меняется автоматически** по мере того, как вы оформляете приёмку, размещаете товар, выполняете операции и отгружаете — вручную его трогать обычно не нужно. Но при необходимости статус можно сменить вручную: на вкладке «Обзор» внутри заявки нажмите на плашку статуса рядом с именем партнёра.

---

## 4. Внутри заявки: рабочее пространство с пятью вкладками

После открытия заявки появляется своё нижнее меню из пяти разделов. Кнопка «Назад» в шапке — выход из заявки к общему списку.

### 4.1. Обзор

- Название партнёра, статус (можно сменить вручную), общий процент готовности операций.
- Список позиций (артикулов) заявки. Под каждой — сколько операций выполнено из скольких.
- Если у позиции написано «Артикул не найден в справочнике SKU» — по ней нельзя провести операции, пока артикул не заведён в справочник (это делается на сайте, не в приложении).
- **Тап по позиции** открывает экран «Обработка» этого артикула (раздел 5 ниже).

### 4.2. Приёмка

Здесь фиксируется физическое поступление товара согласно заявке.

**Как оформить приёмку:**
1. Выберите тип: **Паллетная / Коробочная / Поштучная**.
2. Укажите, кто принял.
3. По каждой открытой позиции введите, сколько принимаете **сейчас**.
4. Нажмите «Оформить приёмку».

**Важно про количество — чтобы не запутаться:**

- Поле «Принять сейчас» **по умолчанию заполнено остатком**, а не полным заявленным количеством. Если по заявке уже что-то приняли раньше, вводить заново всё количество не нужно — только то, что осталось.
- Под полем всегда видно: *«Заявлено: N · принято ранее: N · осталось: N»* — сразу понятно, сколько уже сделано.
- **Больше, чем осталось, ввести нельзя** — поле само не даст ввести лишнее, а сервер дополнительно это проверяет.
- Как только позиция принята **полностью**, она пропадает из формы для ввода и переезжает в отдельный список сверху — **«Уже принято полностью»** с зелёной галочкой. Повторно провести по ней приёмку нельзя — так и задумано, это защита от задвоения.
- Если приняли **не всё** количество на этот раз (т.е. осталось «в долгу» после этой приёмки) или количество отличается от того, что должны были принять — появляется блок **«Тип расхождения»**: отметьте, в чём проблема (качество / наименование / количество / упаковка / дефект) и опишите словами в комментарии.
- Если по заявке уже всё принято до последней позиции — вместо формы вы увидите сообщение «Все позиции по заявке уже приняты» и кнопки оформления не будет.

**История приёмок** — ниже формы, список всех проведённых приёмок по заявке. У каждой:
- отметка **«Частичная приёмка»**, если было расхождение;
- кнопки формирования документов: **МХ-1** (акт приёма-передачи, всегда доступен) и **ТОРГ-2** (при расхождениях — только если приёмка была частичной).

### 4.3. Хранение

Здесь товар «раскладывается» по ячейкам склада.

По каждой позиции показано, на каких адресах и сколько единиц сейчас лежит (или «Товар ещё не размещён», если пусто).

Три кнопки под позицией:

| Кнопка | Что делает |
|---|---|
| **Разместить** | Добавить товар на указанный адрес ячейки (например, `A-01-01`) в указанном количестве. |
| **Переместить** | Перенести товар с одного адреса на другой (обязательно указать оба адреса и количество). |
| **Снять** | Списать товар с адреса (например, при отгрузке или порче). |

«Переместить» и «Снять» недоступны, пока по позиции ничего не размещено. Система не даст снять или переместить больше, чем реально числится на адресе — если попробовать, появится сообщение с точным остатком.

### 4.4. Отгрузка

Оформление передачи товара партнёру.

**Как создать отгрузку:**
1. Выберите способ: **Собственными силами** (нужно указать номер автомобиля и водителя) или **Силами партнёра**.
2. Проверьте/поправьте количество по каждой позиции (по умолчанию — заявленное количество).
3. Нажмите «Создать отгрузку».

Отгрузка появляется в истории со статусом «Не отгружено». Когда товар физически передан — нажмите **«Отметить отгруженной»**, укажите, кто отгрузил. После этого становятся доступны кнопки формирования документов **ТТН** и **МХ-3**.

### 4.5. Документы

Общий список всех документов, сформированных по заявке — МХ-1, ТОРГ-2 (из приёмки), ТТН, МХ-3 (из отгрузки). У каждого — номер, дата и кто сформировал. Это история, ничего оформлять здесь не нужно — документы создаются кнопками на вкладках «Приёмка» и «Отгрузка».

---

## 5. Обработка позиции (артикула)

Открывается тапом на позицию во вкладке «Обзор».

- Наверху — наименование, спецотметки товара (хрупкое, ЧЗ и т.п.), сумма трёх сторон, заявленное количество.
- **«Кол-во по факту»** и **«Артикул при пересорте»** — заполняются, если по факту получилось не то количество или не тот товар, что заявлен. Не забудьте нажать «Сохранить факт».
- Ниже — чек-лист операций **из справочника SKU этого артикула** (какие операции разрешены — определяется на сайте в карточке товара, здесь список только для отметки выполнения, добавить «свою» операцию нельзя).
  - Отметьте галочкой выполненную операцию.
  - Кнопка **«Детали»** раскрывает: факт. количество по этой операции, флаг **«Брак»**, комментарий. Не забудьте «Сохранить» после заполнения.
- Если у артикула нет привязанного справочника SKU — операции по нему недоступны, экран покажет предупреждение об этом.

Процент готовности заявки на вкладке «Обзор» считается по этим отметкам автоматически.

---

## 6. Вкладка «Склад» (верхний уровень)

Не привязана к конкретной заявке — быстрый инструмент сверки:

- Введите адрес ячейки — увидите, какие артикулы и в каком количестве там лежат.
- Ниже — лента последних перемещений по складу (кто, что, куда, когда), зелёным — приход, красным — списание.

## 7. Частые ситуации

| Ситуация | Что это значит |
|---|---|
| Поле «Принять сейчас» не даёт ввести больше цифры | Столько и осталось принять по этой позиции — так и должно быть. |
| Позиции нет в форме приёмки, только в списке с галочкой | Она уже принята полностью, повторно проводить не нужно и нельзя. |
| «Снять»/«Переместить» выдаёт ошибку с остатком | Вы пытаетесь списать больше, чем реально числится на адресе — проверьте фактический остаток и введите корректное количество. |
| Кнопка «Переместить»/«Снять» неактивна | По этой позиции ещё ничего не размещено на складе — сначала «Разместить». |
| В «Обработке» нет списка операций, только предупреждение | Артикул не привязан к справочнику SKU — нужно завести его в справочнике на сайте. |
| Приложение долго грузит / ошибка сети | Проверьте Wi-Fi; приложение само повторяет запрос при кратковременном обрыве, но не бесконечно. |
